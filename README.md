# Owner · 个人工作台

独立的个人工作台，采用贾维斯风格 HUD：深蓝底色、青色数据线、环形核心与琥珀色提示。P1 的 React 界面与交互迁移已实现，主要流程已验证；手写原型继续保留作为对照。

## 打开

开发环境：Node.js 22.13+（本机验证 22.22.0），或受依赖支持的 Node.js 24+。初次获取仓库执行 `npm ci`，锁文件固定依赖版本。

React 开发入口：

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:4173/#overview`；`npm run dev:app` 等价。React 开发入口接管原型原先使用的地址，以便读取同一浏览器、同一来源保存的记录。

现有原型继续通过下列命令打开，也支持直接打开 `dist/index.html`：

```sh
npm run dev:prototype
```

原型静态服务现在默认使用 `http://127.0.0.1:4174`。`npm run dev` / `npm run dev:app` 启动 React 开发入口；先运行 `npm run build`，再通过 `npm start` / `npm run preview:app` 在 `http://127.0.0.1:5175` 预览生产构建。服务只绑定回环地址，端口占用时明确报错，不自动更换地址。

`4173`、`4174`、P0 的 `5173`、`file://`、`localhost` 与 `127.0.0.1` 属于不同的数据空间；不会自动合并。需要切换地址时，先在原地址导出。P1 仍使用兼容的 `owner.workbench.prototype.v1`，没有执行 Dexie 迁移。

## P1 迁移的界面与流程

以下功能已实现迁移。`npm run verify` 全部通过，包含 57 项测试；导航、待办、心情、日程和目标等主要流程已完成浏览器验证。实际验证范围与尚待检查的项目见 [P1 记录](docs/P1_REACT_MIGRATION.md)。

- 总览：紧凑标题与快速记录入口，资产摘要在「我的近况」上方；默认第一排身体、饮食，第二排学习 / 工作、习惯。窄屏单列。每张卡标注自己的时间口径，总览不受详情页时间切换影响。
- 今日待办：位于资产与近况之间，展示今天及此前未完成的前 3 项；可快速添加、撤销刚添加的事项、勾选完成和查看全部。今日完成项默认折叠，使用原有任务数据并保存在本地。学习 / 工作卡片只保留投入摘要，避免重复展示待办。
- 心情与精力：身体卡片记录每日心情、1～5 分精力和可选原因，身体详情按时间范围回看；与睡眠、体重记录分别保存。
- 日程与重要日期：今日待办内展示今天、未来 7 天和此前未完成的日程，按日期和时间排序；支持全天、具体时间、类型、备注及完成 / 恢复。当前为单次日期，不含循环日程和系统通知。
- 阶段目标：学习 / 工作卡片展示主要目标，最多管理 3 个目标；支持手动进度、目标日期、下一步行动，以及将下一步加入今日待办。相同目标的同一未完成行动不会重复加入。
- 领域页面：点击侧栏或卡片详情进入独立视图，支持浏览器前进 / 后退及刷新；身体、习惯、饮食、投入可切换近 7 / 30 天，资产显示账户明细、构成和近 30 天历史。
- 记录：顶部「快速记录」可选择身体、习惯、餐食、专注投入和账户余额，或保存随手记；卡片保留补充记录、习惯打卡和待办入口，面板随记录更新。
- 布局与外观：近况四张卡片可拖动六点按钮排序，也可聚焦按钮后用左右方向键排序；支持「贾维斯 · 青蓝」和「深空 · 冰蓝」外观；资产金额隐藏。旧版配色自动映射为青蓝主题，记录及其他偏好保留。`dist/jarvis.css` 集中管理 HUD 外观。窄屏改为顶部导航，设置仍可通过右上角个人按钮访问。
- Agent 悬浮窗：点击右下角「个人 Agent」展开；关闭按钮、再次点击入口或 Esc 可收起。面板中的「交给 Agent」会自动展开并带入上下文；对话、任务、产物保留在窗内，支持导出 Markdown。
- 设置：导出当前全部记录为 JSON，查看随手记，恢复初始示例。

## 当前范围

初始数据全部是示例，以 2026-10-14 为原型参考日期，顶部明确标注示例日期，卡片中的「今天」「昨晚」均相对该日期。记录与界面偏好仍保存在当前浏览器的 localStorage。旧默认卡片顺序会更新为新版顺序，自定义顺序继续保留。

React 过渡存储读取旧结构并保留未知扩展字段；缺少后加的心情、日程和目标集合时补为空集合。无效 JSON、未知版本、无法识别的记录或存储读取失败时保留原始内容，显示警告、暂停写入，仅供查看示例；不会把示例静默覆盖到原记录。保存失败保留现有数据与编辑草稿。上次未完成的 Agent 任务显示为已中断。

记录编辑保留打开时的目标基线；保存和删除前重新核对。同一记录已被其他页面修改或删除时，保留草稿并拒绝覆盖；无关记录或外观偏好的更新不算该记录的冲突。

Agent 回复由本地规则生成，用于验证交互，没有接入 AI 模型。外部账户同步、表格 / 账单导入、正式数据库、账户认证和桌面打包均尚未实现。原型不访问外部账户或健康设备。

`reference/` 内的项目截图仅用于设计参考，不被原型页面加载。

## 文件

- `dist/index.html`：应用结构与表单。
- `dist/app.css`：外观、主题、响应式布局。
- `dist/app.js`：示例数据、记录逻辑、图表和 Agent 演示。
- `dist/jarvis.css`：贾维斯 HUD 视觉样式。
- `server.cjs`：无依赖的本地静态服务。
- `src/app/`：React 应用、hash 导航和过渡存储 hook。
- `src/features/`：总览、领域详情、记录表单与 Agent 工作区。
- `src/domain/`：领域类型、统计与日期范围选择器。
- `src/data/prototype.ts`：固定示例数据、旧结构兼容与安全读写。
- `vite.config.ts`、`tsconfig*.json`：开发、构建与严格类型配置。
- `scripts/build.mjs`：限制输出为 `build/`，构建前后核对原型文件指纹。
- `tests/`：构建保护、过渡存储、编辑冲突、统计、React 静态渲染及 Agent 规则测试。

注意：`dist/` 现在是手写源码，已纳入 Git；并非可以删除的构建目录。

## 检查与构建

```sh
npm run check
npm run verify
npm run preview:app
```

`check` 继续检查原型语法；`verify` 执行语法、类型、lint、格式、测试和生产构建。`build/` 是生成目录，不提交 Git；构建不会覆盖手写 `dist/`。`preview:app` / `npm start` 在构建完成后通过 `http://127.0.0.1:5175` 验证产物。完整命令见开发指南。
