# Owner · 个人工作台

独立的个人工作台，采用贾维斯风格 HUD：深蓝底色、青色数据线、环形核心与琥珀色提示。React 界面现已接入真实日期与 IndexedDB 本地存储；手写原型继续保留作为对照。

## 打开

使用 Node.js 22.13+（验证版本 22.22.0）或受依赖支持的 Node.js 24+。

```sh
npm ci
npm run dev
```

开发入口为 http://127.0.0.1:4173/#overview。Windows 若 npm.ps1 受限，使用 npm.cmd。

| 命令 | 用途 |
| --- | --- |
| npm run dev / npm run dev:app | React 开发入口，4173 |
| npm run dev:prototype | 保留的手写原型，4174 |
| npm run build | 类型检查后构建到 build/，保护 dist/ 指纹 |
| npm start / npm run preview:app | 生产预览，5175 |
| npm run check | 原型及服务 JavaScript 语法检查 |
| npm run verify | 语法、lint、格式、测试、类型与构建 |

所有服务只绑定回环地址，端口占用时报错。4173、4174、P0 的 5173、file://、localhost 与 127.0.0.1 属于不同数据来源，不自动合并；尽量保持原地址 4173。

## 日期与记录空间

- **正式记录**：默认空数据，使用设备本地日期；总览、详情和 Agent 使用相同日期范围。跨午夜最长约 15 秒刷新，后台恢复或重新获得焦点时也会刷新。
- **示例体验**：独立示例数据，固定参考 2026-10-14，不进入正式统计。
- **原型记录**：旧 localStorage 经预览后整体复制的空间，保留日期、来源与偏好，固定参考 2026-10-14。

有旧记录时首次打开进入只读预览。打开顶部「旧记录迁移报告」，核对数量、日期范围和未知来源，可下载原始备份，再点击「复制到原型空间」。旧 key `owner.workbench.prototype.v1` 保留且不反向写入。格式错误、重复 ID、无效关联会停止迁移，原始内容仍可下载和重新读取。

进入原型空间后，可通过「选择旧记录到正式空间」按领域、日期预览复制；来源不明项需主动勾选。复制保留日期和来源，重建目标关联，跳过已复制项，拒绝覆盖同日正式记录或同名同类账户。原型净资产历史、Agent 对话、产物和随手记继续留在原型空间。

记录与空间偏好保存在当前浏览器 IndexedDB 数据库 `owner.workbench.v2`。新增记录使用事务保存；保存失败保留草稿。标签页订阅数据库变动，同一记录的旧草稿不能覆盖其他页面的修改。未知历史创建时间保留为空，迁移时间另记。睡眠按起床日期记录，旧任务缺少完成日期时不计入「今日完成」。

实现和验收范围见 [P2 日期与存储](docs/P2_DATE_STORAGE.md)。

## 界面与记录

- 总览顺序：资产 → 今日待办（含日程）→ 我的近况。
- 近况四张卡片默认身体、饮食、学习 / 工作、习惯，可拖动六点按钮或聚焦后用左右方向键排序。
- 身体记录睡眠、体重、步数、心情与精力；饮食记录餐食和估算热量；投入记录分钟、任务与阶段目标。
- 待办包含今天及此前未完成事项，支持添加、撤销刚添加的事项、完成和查看全部；缺少完成日期的旧任务仍可在全部待办查看。
- 日程支持单次全天或本地时间及其时区；目标最多 3 个，下一步可加入待办。
- 账户按人民币整数分保存，支持隐藏金额，资产与负债分开计算。账户快照可在资产详情中按账户查看。
- 领域详情支持近 7 / 30 天；导航保留 hash、刷新和浏览器前进后退。
- Agent 在右侧点击展开，含对话、任务和产物，支持 Markdown 导出。回复由本地规则生成，尚未连接 AI 模型。
- 领域详情支持搜索、查看与管理全部记录；待办与随手记可独立编辑和删除。
- 习惯支持新增、改名、停用和重新启用，按各日期的启用区间计算计划。
- 普通删除进入回收站，恢复遇到同日 / 同 ID 冲突时停止，不覆盖当前记录。
- 设置提供完整备份与恢复、回收站和习惯配置；仅示例体验空间提供恢复初始示例。

个人设置 → **备份与恢复** 可导出所有空间、偏好、账户快照、回收站、恢复点及旧原文。选择完整备份 JSON 后先预览，默认建立独立恢复副本；替换当前空间需确认，且先自动保存恢复点。回退之前也会保存当前内容。

完整备份格式 v1，限制 20 MB。旧版「当前显示记录」JSON 暂不支持直接导入，保留的该导出按钮仅供查看。旧 localStorage 的迁移入口继续可用，不会被文件导入覆盖。见 [P3 记录闭环与备份](docs/P3_RECORDS_BACKUP.md)。

P4 已接入按类型延迟加载的 ECharts：身体趋势、习惯热力图、投入统计与资产构成，配有日期范围、单位、来源和可键盘打开的数据表。图表和摘要共用统计输入，缺失不补零；金额隐藏时同时隐藏资产图表与数值表。

本地版本为 0.3.0，133 项测试通过。实现及浏览器验收范围见 [P4 统计图表与首版验收](docs/P4_CHARTS_RELEASE.md)，日常使用见 [数据口径与恢复指南](docs/DATA_AND_RECOVERY.md)。没有引入后端、云同步、模型 API、外部设备或桌面打包；已加载页面可本地操作，尚未实现 PWA 离线冷启动。

## 开发文件

- `src/app/`：应用外壳、hash 导航和数据库订阅。
- `src/features/`：总览、领域详情、表单、空间管理及 Agent 浮窗。
- `src/domain/`：类型、Zod schema、统计及存储接口。
- `src/data/indexeddb/`：Dexie 表、事务、金额单位、账户快照与适配。
- `src/data/migrations/`：旧数据报告、原子迁移、领域日期复制。
- `src/shared/date/`：可注入时钟、本地日历与日期运算。
- `src/data/prototype.ts`：固定示例及旧结构兼容，旧写入函数仅留作兼容测试。
- `tests/`：构建保护、日期、统计、事务、迁移、编辑冲突和 React 渲染测试。
- `docs/`：[计划](docs/IMPLEMENTATION_PLAN.md)、[清单](docs/ROADMAP.md)、[开发指南](docs/DEVELOPMENT.md)。
- `reference/owner-jarvis-overview.jpg`：已确认的视觉基线。
- `dist/`：已跟踪的手写原型源码，不能清空或当成构建输出删除。

凭据、个人导出、数据库和个人备份不得提交 Git。生成的 build/ 不提交。
