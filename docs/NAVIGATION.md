# 模块切换体验

日期：2026-10-28。范围：React 应用导航优化，不修改 dist/ 手写原型。

## 行为

- 左侧选中背景与青色光条在 160ms 内滑到新位置；窄屏改为沿顶部导航横向移动。文字选中态立即反馈。
- 同位置切换优先采用浏览器原生 View Transitions：旧内容 90ms 淡出，新内容 200ms 淡入并上移 6px，标题 120ms 淡入。顶部框架、环形核心与 Agent 不参与页面快照。
- 浏览器不支持原生过渡或需要恢复较远的滚动位置时，新内容轻量淡入，避免跨屏拉伸。开启减少动态效果后直接更新，运行中的动效也会取消。
- 连续点击立即更新选中项，取消旧过渡；仍在加载的旧请求不能覆盖最后选择。动画结束不是页面状态生效的条件。
- 首次进入一个模块从顶部开始；再次进入及浏览器前进 / 后退恢复该模块的滚动位置。重复点击当前模块保持位置。
- 滚动位置按记录空间和模块分开，仅保存在当前标签会话内；刷新或关闭标签后重新开始，不向 localStorage 或 IndexedDB 新增偏好。
- 鼠标移入或键盘聚焦详情导航时提前加载共享详情模块。等待超过 150ms 时显示正在打开的模块，短等待不闪烁提示。首次直达有固定布局占位和失败重试；导航加载失败保持当前内容并提示重试。
- Agent 草稿与窗口保持；上下文随成功切换更新，也可手动切回总览。当前导航上下文属于会话状态，任务记录和产物仍按原有事务保存。

## 实现边界

`usePageNavigation` 管理 hash、浏览器历史、滚动和可取消动效；`NavigationIndicator` 根据真实按钮布局定位，监听尺寸变化；`detailModule` 共用动态导入并在失败后允许重试。图表引擎仍按类型延迟加载，空数据不提前加载图表。

不新增动画依赖、数据库结构或数据迁移。正式日期、记录保存 / 冲突检查、备份恢复和金额隐藏保持原有规则。数据层保留旧 context / selected 字段兼容已有备份，导航不再为切换上下文写入记录空间。
