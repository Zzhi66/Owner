# P4 · 统计图表与首版验收

版本：0.3.0。日期：2026-10-19。分支：`codex/p4-charts-release`，基于 P3 提交 `b09223e`。

## 实现

- 接入 Apache ECharts 6.1.0，保留总览的小型 SVG 与 HUD 装饰。
- 身体详情：睡眠、体重、活动量趋势；投入详情：每日小时柱状图与按项目分钟汇总。
- 习惯详情：按各日期计划计算的日历热力图，区分缺失、未安排与明确记录为零；停用计划保留历史。
- 资产详情：现金 / 投资 / 其他资产环图，负债单独列示；估值历史按 7 / 30 天切换，账户快照不冒充流水。
- 每张图提供绝对日期范围、单位、空间来源、文本摘要和可通过键盘展开的完整数据表；资产隐藏时不在图、标签或数据表中残留金额。
- 总览睡眠 SVG 也保留日期空缺，不再将稀疏记录连成连续趋势。工作页待办完成数改为按当前日期范围统计，排除未知完成日期。

## 模块与资源

`src/domain/statistics.ts` 为图表与文本摘要提供纯统计输入；不新增数据库结构，不改变已有记录。

图表仅在有数据时加载。`trend-engine`、`habit-engine`、`asset-engine` 分别注册所需图表；共享 `engine` 使用 SVGRenderer、Grid、Tooltip 等模块，未引入整包全量入口、CanvasRenderer 或远程 CDN。配置依据 [ECharts 按需导入](https://echarts.apache.org/handbook/en/basics/import/) 和 [容器与生命周期](https://echarts.apache.org/handbook/en/concepts/chart-size/)。

`mountChart` 管理异步导入、ResizeObserver 和 dispose；导航离开时清理，延迟导入在卸载后不会创建实例，初始化失败也释放已创建资源。图表关闭动画，读取数据不依赖悬停；Tooltip 使用 richText，完整数据通过原生 HTML 表格提供。

Vite 生产 manifest 与 `scripts/production-audit.mjs` 纳入正式构建入口：检查静态首屏没有图表引擎、三类延迟入口存在、引用资源均在 build/ 且存在、每个 JS 分包不超过 500 kB、HTML 不依赖外部脚本或样式。构建前后继续核对 dist/ 文件树与 SHA-256。

本次构建主入口约 91.02 kB（gzip 25.44 kB），共享图表引擎约 493.93 kB，趋势 / 热力 / 环图入口约 52.25 / 56.01 / 15.95 kB。主入口大小不等于首屏全部下载量，React、数据库与校验库仍为首屏依赖。分包阈值用于发现回归，不代表已经完成性能基准测试。
