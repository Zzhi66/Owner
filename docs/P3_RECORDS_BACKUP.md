# P3 · 记录闭环与完整备份

日期：2026-10-18。应用版本：0.2.0。开发分支：`codex/p3-records-backup`。

## 已实现

- 领域详情新增「查看与管理全部记录」，支持搜索、分页显示、新增、编辑及删除。身体、心情、饮食、投入、账户和习惯日志沿用各自字段和校验。
- 全部待办支持独立新增、编辑、日期、项目、完成状态、目标关联及删除；随手记可编辑和删除。目标与日程原有管理入口继续可用。
- 编辑已有餐食或专注记录会更新原 ID，不追加重复记录；编辑专注记录不重复生成待办。各类编辑、删除均核对目标基线，保存失败保留草稿。
- 习惯支持新增、改名、停用与重新启用。稳定 ID 保留日志关联，按历史启用区间计算每日计划；新增习惯不改变此前的分母，停用不删除日志。
- 账户快照支持按账户筛选、查看估值日期、来源、保存时间和人民币金额；删除账户不删除其历史快照。快照与手动净资产汇总均不代表收支流水。
- 设置新增「备份与恢复」「打开回收站」「配置习惯」，继续保留仅供查看的当前显示记录导出。
- 总览顺序、中文 HUD、金额隐藏和右侧 Agent 悬浮窗保持。修正身体详情底部遗留的固定 10/14 范围结尾，改为当前空间当天。

## 数据升级

数据库名称仍为 `owner.workbench.v2`，Dexie schema 升级至 3：version 2 添加 trash / recoveryPoints 并补齐习惯定义的 periods，version 3 添加 legacyArchives。P2 的 version 1 → 3 使用实际 IndexedDB 模拟升级测试；不删除旧表、不清空 localStorage，不改写既有打卡、身体记录或账户余额。

习惯定义包含 id、name、periods。区间采用 `[from, to)`；省略 to 表示继续启用。旧默认习惯按原有历史口径启用，来源不明的旧习惯日志保留，未识别的定义不自动进入计划。总览、详情、Agent 共享按日计划分母。

新表：

| 表 | 内容与索引 |
| --- | --- |
| trash | 删除操作的分组副本；id、spaceId、deletedAt |
| recoveryPoints | 替换 / 回退前的空间快照；id、spaceId、createdAt |
| legacyArchives | 从备份保留的旧原文，仅下载核对；id、capturedAt |

## 删除与恢复

普通删除在写入事务中把被移除的完整行、来源和元数据保存到回收站，按一次操作分组。数据库失败时，删除与回收副本一并回滚。

回收站恢复使用原 ID、原日期和元数据。已有相同 ID / 日期、关联不完整或恢复后目标超过 3 个时停止整个恢复；不覆盖当前记录，回收站也保持原样。目标删除后保留已生成待办并解除关联；恢复目标不会自动重绑待办，可在待办编辑中手动选择。

当前不提供永久清空、自动过期删除或删除恢复点的操作。回收站、快照与恢复点会持续占用本地空间，完整备份会保留它们。

## 完整备份格式

入口：个人设置 → 备份与恢复 → 导出完整备份（所有空间）。

JSON 格式标识为 `owner-workbench-backup`，format version 1、databaseVersion 3、appVersion 0.2.0。包含导出时间、所有新版空间及偏好 / 未知扩展、全部领域行、账户快照、迁移原文与标记、回收站、恢复点和旧原文存档。数据库 metadata 只导出必要的空间选择，不导出任意设置或凭据。

导出同时读取原有 localStorage key 的完整文本，作为可下载旧原文存档保留，即使它解析失败也不丢弃；不会因为旧记录尚未迁移而遗漏这份原文。导入不把这些原文写回 localStorage。

文件限制：20 MB、100000 条记录（包含历史和恢复点）、最多 100 个空间。旧版「当前显示记录」JSON 不是完整备份，目前不支持直接导入；旧 localStorage 仍走 P2 的报告与迁移流程。

## 导入与恢复点

1. 读取前检查文件大小，再校验 JSON、格式版本、字段类型、数值范围、复合 ID、空间归属、目标 / 产物关联、重复项、整数分与迁移原文哈希。
2. 用户选择来源空间和导入方式，点击预览后显示记录、账户快照、回收组和恢复点数量。
3. 默认建立独立恢复副本，保留原日期、来源、实体 ID 和关联；空间 ID 重映射，恢复副本名称自动去重。其他空间不变，不自动混入正式统计。
4. 替换当前空间需要同类型来源和明确勾选。事务内核对预览 revision，先建立恢复点，再替换该空间的记录、快照和回收内容；其他空间保留。
5. 回退恢复点前再保存当前内容。示例重置也会先建立恢复点。替换和回退失败均整体回滚，不留下半份空间或虚假恢复点。
6. 导入中的运行任务标为已中断，不生成演示结果；当前正在运行 Agent 时暂停导入 / 回退。

未知版本、坏文件、超限文件和过期预览均不会写入。旧原文只作为存档下载；运行时不会执行原文或文件中的指令。恢复点不递归包含其他恢复点，防止备份无限嵌套。
