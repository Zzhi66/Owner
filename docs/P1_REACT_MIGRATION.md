## 交付范围

- React 组件替代原先的工程说明页，沿用中文贾维斯 HUD、SVG 环形核心和右侧可展开的 Agent。
- 总览保持资产 → 今日待办（含近期日程）→ 个人近况；身体、饮食、投入、习惯支持用户排序。
- hash 导航覆盖总览与身体、习惯、饮食、学习 / 工作、资产详情；详情保留近 7 / 30 天范围和 SVG 统计。
- 记录表单、心情与精力、日程、目标、随手记、待办、资产隐藏、主题和导出通过 React 事件与草稿提交实现。
- Agent 保留本地规则演示、上下文、对话 / 任务 / 产物标签、任务进度和 Markdown 产物。固定 900 ms 演示流程不调用模型；重复发送被锁定，旧运行任务在重新加载后显示已中断。
- 领域类型、纯统计选择器、过渡存储与可测试的 Agent 汇总从界面中分离。
- 构建继续输出 `build/`，`dist/` 原型作为受保护的手写源码完整保留。

本阶段仍使用固定示例日期 2026-10-14 和 localStorage v1。没有接入 Dexie、Zod、ECharts、真实日期、云同步、模型 API、Three.js 或桌面打包；正式数据迁移属于 P2。

## 开发入口切换

| 用途 | 命令 | 地址 |
| --- | --- | --- |
| React 默认开发入口 | npm run dev / npm run dev:app | http://127.0.0.1:4173/#overview |
| 原型对照 | npm run dev:prototype | http://127.0.0.1:4174/#overview |
| 生产产物预览 | npm run build，再 npm start / npm run preview:app | http://127.0.0.1:5175/#overview |

以上来源的记录互相独立。React 在原型过去的 4173 读取同一浏览器来源中的旧记录；5173 是 P0 工程入口的旧来源，不会自动读取或合并其数据。4174 的原型也不会自动看到 4173 的记录。`localhost` 与 `127.0.0.1` 不等价，直接打开 file:// 也有独立存储空间。

切换前从原地址导出；P1 的导出不是完整恢复能力，导入及事务恢复按 P3 实施。不要清理旧来源来获得所谓“干净”页面。端口被占用时，只停止已确认属于本项目的旧服务，再运行新的入口。

## 兼容与失败保护

过渡适配继续使用 `owner.workbench.prototype.v1`，保留原日期、记录 ID、来源及未知扩展字段。规范化旧主题、默认顺序和选项；只把缺少的 wellbeing、events、goals 视为空集合。用户已有的自定义排序及记录不被示例覆盖。

无效 JSON、未知版本、结构无法识别或存储不可读取时，原始值保留，界面提示警告、暂停写入，示例仅供临时查看。保存前再次校验现有原始结构；写入失败不提交新状态或关闭编辑草稿。跨标签变化与过期编辑需提示，不能静默覆盖。此保护不等于实现正式迁移、数据库事务或通用冲突合并。

记录编辑器捕获打开时的目标记录基线，在保存与删除前重新比较。同一记录已在其他页面修改或删除时，即使本页已同步最新全局状态，也保留草稿并拒绝覆盖；已删除的目标不能被旧草稿重新创建。无关记录与偏好更新不触发该目标的冲突。身体 / 心情切换日期加载对应记录时更新日期基线。自动测试与两标签日程编辑实测均已通过。

Agent 的文字与用户记录经 React 文本渲染，不作为 HTML 执行。关闭浮窗不终止正常演示任务；卸载清理计时器并尝试保留中断状态，重载时兼容旧运行任务。产物始终标注本地规则生成，不能视为真实 AI 分析或外部操作结果。
