# 数据口径与恢复指南

适用于本地第一版 0.3.0，2026-10-19。

## 日常使用与统计

固定使用同一个浏览器和地址，开发入口为 `http://127.0.0.1:4173`。不同端口、`localhost`、`file://` 与 `127.0.0.1` 的记录不互通。先在顶部核对记录空间，再新增或查看记录。

| 项目 | 统计口径 |
| --- | --- |
| 正式记录 | 设备本地日历日期，7 / 30 天含今天和起始日；跨天刷新由日期服务处理 |
| 示例体验、原型记录 | 固定参考 2026-10-14，与正式空间隔离；示例值不等于真实个人记录 |
| 睡眠 | 按起床日期；均值仅包含有数值的日期，缺失不补零，折线不跨缺失日期连接 |
| 体重与步数 | 保留原始记录；记录为 0 与没有记录分开显示 |
| 习惯 | 按各日期启用的习惯计划计算；停用不删除历史。热力图以每日完成率着色，空格表示未记录或未安排；数据表进一步区分两者 |
| 习惯完成率 | 已完成次数 / 当日全部计划次数。部分习惯未打卡时，不代表已确认这些习惯未完成。计划外打卡保留在全部记录中，不进入计划完成率 |
| 投入 | 当前范围内分钟合计后换算小时；无专注记录的日期保留空缺。项目表同时提供分钟与小时 |
| 待办完成数 | 按完成日期和当前范围统计；没有完成日期的旧任务不计入范围完成数 |
| 饮食 | 录入的热量是估算，缺失热量保留为空；没有记录不能解释为没有进食 |
| 资产构成 | 当前保存的账户余额，人民币；整数分计算后展示元。现金、投资、其他资产组成总资产，负债单列，净资产 = 总资产 − 负债 |
| 资产时间 | 各账户保留自己的估值日期；构成不随历史范围回溯。历史估值单独按所选范围展示，不通过账户快照编造连续净资产或流水 |

详情页的图表、摘要和数据表使用相同统计输入。数据表可通过键盘打开；图表模块加载失败时仍能查看数据表。金额隐藏后，资产详情的构成、估值图与对应数值表一并移除。

当前数据来自当前空间保存的记录，没有设备或云端自动同步。Agent 为本地规则演示，回复和产物均明确标注演示。

## 备份

1. 打开个人设置 → **备份与恢复**。
2. 点击 **导出完整备份（所有空间）**，保存下载的 JSON 文件。
3. 将备份文件留在浏览器存储之外的位置；更换浏览器、地址或清理站点数据前再次备份。

完整备份含各空间、记录、关联、偏好、账户快照、回收站、恢复点及旧原文存档。格式为 `owner-workbench-backup` v1，当前限制 20 MiB。应用版本升级不等于备份格式版本升级。

「导出当前显示记录」只供查看，不能当作完整恢复文件。完整备份包含个人信息，存放和分享时按个人文件管理，不提交 Git。

## 恢复文件

1. 打开 **备份与恢复**，选择完整备份 JSON。
2. 校验完成后选择来源空间。默认 **建立独立恢复副本**，先预览数量，再确认。
3. 应用切换到恢复副本后，检查空间名、日期、记录列表和图表数据表；原有空间仍保留。
4. 确需覆盖时，选择 **替换当前空间**，只能用同类型来源替换。核对预览并确认后，系统先建立原空间的恢复点，再原子替换。

无效 JSON、未知格式版本、超限文件、冲突或事务失败会停止操作，不留下半份导入。当前不提供两份备份自动合并；保留两边副本后再决定如何整理。

## 撤销删除与回退

- 普通删除：个人设置 → **打开回收站** → 恢复对应分组。ID、同日记录或关联冲突时停止恢复，不覆盖当前内容。
- 替换后回退：**备份与恢复** → 当前空间的恢复点 → 预览 → 核对并确认。回退前会保存当前内容，因此仍可再次恢复。
- 旧原型记录：打开顶部迁移报告，先下载原始内容再复制。旧 localStorage key 不被新版覆盖；旧原文存档也不会自动写回旧 key。

## 本地能力边界

记录保存在当前浏览器 IndexedDB；文件备份需要主动导出，恢复点与数据库位于同一来源，不能替代外部备份。浏览器站点数据被清理后，只能用保存在外部的文件恢复。

页面和所需模块已经加载后，本地记录、统计、备份以及规则 Agent 不需要远程服务。尚未加载的模块仍需从应用地址取得；当前没有 Service Worker / PWA，不能保证断网冷启动或刷新后可打开。没有后端、云同步、真实模型 API、Three.js 或桌面安装包。
