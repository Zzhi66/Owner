# P2 · 日期与可靠存储

日期：2026-10-18。开发分支：`codex/p2-date-storage`。

## 交付

React 应用改用 Dexie / IndexedDB 作为持久来源，提供真实日期、三个隔离空间、旧数据报告与迁移、选择性复制、多标签更新和冲突保护。保留 HUD、资产 → 待办 → 近况顺序、中文及右侧 Agent 浮窗。`dist/` 手写原型未修改。

| 空间 | 初始内容 | 日期 | 用途 |
| --- | --- | --- | --- |
| 正式记录 | 空集合及默认偏好 | 设备本地当天 | 个人日常记录 |
| 示例体验 | 独立示例 | 2026-10-14 | 体验与参考 |
| 原型记录 | 用户预览后复制的旧原文 | 2026-10-14 | 保留原日期、来源及偏好 |

有旧 localStorage 时先进入只读预览，不自动复制到正式空间。顶部可切换空间，打开表单或 Agent 正在运行时暂停切换。不同标签保留各自当前空间，数据库中的最近选择用于下次打开。

## 数据与事务

- 数据库名 `owner.workbench.v2`，Dexie schema version 1，独立于 UI 兼容投影的 `schemaVersion: 1`。
- 表：spaces、metadata、migrations、daily、wellbeing、meals、sessions、habitDefinitions、habitLogs、tasks、events、goals、accounts、accountSnapshots、assetHistory、notes、messages、agentTasks、artifacts。
- 领域表使用 `[spaceId+id]` 复合主键，索引 spaceId 和 `[spaceId+date]`。按日唯一的实体以日期为 ID，习惯日志以日期与习惯 ID 的组合为 ID。
- 每行包含 spaceId、稳定 ID、业务日期、来源、顺序、createdAt、updatedAt、migratedAt。新记录元数据使用真实 UTC 时间；旧未知创建 / 更新时间为空，迁移时间单独记录。
- 账户和快照存 amountMinor 整数分及 CNY；UI 适配转换为元，金额显示保留最多两位小数。资产合计先按整数分求和。
- 原型 assetHistory 独立标注 valuationKind=prototype，不能作为账户流水。正式空间的 manual-aggregate 是当次录入后余额的手动汇总，不是历史时点的自动重建。
- 空间 base 只存偏好和未知扩展；UI WorkbenchState 由领域表投影生成，避免 localStorage 和 IndexedDB 相互覆盖。
- Zod 验证结构、日期与数值范围；另核对重复 ID / 日期及目标、产物关联。旧数据不满足新约束时停止迁移，保留原文并显示具体原因。
- 存储接口位于 `src/domain/ports/workbench.ts`，适配位于 `src/data/indexeddb/store.ts`。提交 Promise 在事务提交后才成功；失败不会关闭表单或清空草稿。

写入在同一事务内核对空间 revision、应用变更、验证数据、更新行及 revision；旧 revision 被拒绝。`liveQuery` 订阅其他连接的提交。编辑器同时核对打开时的目标基线，避免同步到最新全局状态后旧草稿仍覆盖已修改的目标。无关记录更新先同步后仍可正常编辑；恰好竞争的提交则提示重试。

账户余额变动开始积累快照，完整账户快照浏览、删除恢复、版本化备份恢复属于 P3。

## 迁移与恢复入口

1. 只读读取 `owner.workbench.prototype.v1`，显示数量、日期范围和来源不明数量，可下载原始文本。
2. 用户确认「复制到原型空间」后校验最新原文；预览后原文发生变化时要求重新核对。
3. 在事务外计算原文 SHA-256，在一个事务中写入原型空间、领域记录、原始文本与迁移标记。
4. 相同原文重复迁移返回同一空间，失败全部回滚，可重试。不同原文快照建立独立空间，不覆盖之前的副本。
5. 全程不删除、不修改旧 key，不按标题猜测示例，也不把迁移时间伪装成历史创建时间。

迁移报告保留解析和结构错误，提供「下载原始备份」「重新读取」。当前没有损坏原文的自动修复编辑器或任意备份文件导入器；用户可保留原文，继续使用独立正式 / 示例空间。

在原型空间打开「选择旧记录到正式空间」，按领域及日期预览。未知来源默认跳过，用户勾选后纳入预览。保留原日期和来源，关联目标重新映射 ID；已有同日记录、同名同类账户或目标超限会阻止整个复制，源 / 目标 revision 变化要求重新预览。copiedFrom 保留来源，重复选择跳过已复制项。

此入口支持身体 / 心情、习惯、饮食、投入 / 待办 / 目标、账户和日程。原型资产历史、Agent 对话、产物和随手记保留在原型空间。复制预览默认隐藏账户金额，可主动显示。

## 日期口径

- `Clock` 可注入；DateService 使用设备 IANA 时区生成本地 YYYY-MM-DD，创建 / 更新时间使用 UTC。
- 日期加减采用日历运算，不以 24 小时毫秒数跨越夏令时；7 / 30 天包含今天，排除未来记录。
- 每 15 秒及 focus、pageshow、visibilitychange 刷新当天；总览、详情、Agent 范围共享当前空间日期。
- 睡眠按起床日期；缺失数值保留 null，零值不当成缺失。
- 未完成过期待办继续展示；旧已完成任务没有完成日期时，不计入今日完成，仍在全部待办中可见。
- 今日勾选完成记录 UTC 时间；补录历史已完成工作时使用用户所选业务日，不伪造历史时刻。
- 全天日程保存日期和空时间；有时间的新增日程保存本地日期、HH:mm 和时区。旧日程未知时区保留为未知，不静默套用设备时区。首版不做跨时区日程自动换算或重复日程。
- 本地 Agent 演示任务有 15 秒租期；启动及周期检查将过期运行任务标记中断，保留未过期的其他标签任务。
